# Pixel Loom

无需后端的像素动画编辑器。打开 `index.html` 即可使用。

## 功能

- **图层组（可嵌套）**：图层 / 组任意嵌套；子层可改名（双击）、显隐、锁定、拖拽或按钮调整层级；隐藏或锁定组会限制整组——绘制、填充、粘贴、批量清空、水平 / 垂直翻转一律被拒绝，状态栏提示与结果一致，且无效操作不会进入撤销历史。
- **每帧按图层保存像素**：每帧独立保存各图层画面，合成视图 = 可见图层自底向上叠加。
- **时间轴**：点击 / Ctrl+点击 / Shift+点击多选帧，拖拽换序，逐帧停留时长（毫秒），选区可设为循环区间，支持循环 / 单次 / 往复播放。
- **批量处理**：对选中帧批量设置停留、清空当前层、水平 / 垂直翻转、删除。
- **跨帧跨层复制**：`Ctrl/⌘+C` 复制当前层画面，切换帧或图层后 `Ctrl/⌘+V` 粘贴。
- **撤销 / 重做**：绘制与结构变更（增删图层 / 帧、移动、重命名等）均可回退。
- **本地恢复**：编辑后自动保存至浏览器本地存储，刷新自动恢复；兼容迁移旧版单层存档。
- **合成导出**：导出当前帧 PNG 或全部帧精灵表（均为可见图层合成结果）。
- 绘制工具：画笔 / 橡皮 / 填充 / 取色，缩放、网格、洋葱皮。

## 测试

```bash
npm install
npm test          # 等价于 node --test test/model.test.js test/dom.test.js
```

- `test/model.test.js`：数据模型测试（图层树、每帧每层像素、撤销重做、批量、播放器等），直接在 Node 中加载 `index.html` 的模型层。
- `test/dom.test.js`：jsdom 冒烟测试（启动页面、模拟绘制、自动保存与恢复、导出、播放）。
